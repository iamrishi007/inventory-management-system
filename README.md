# Inventory Management System

A full-stack Inventory Management System for managing products, inventory, users, roles, permissions, and business statistics through a modern dashboard.

## 🚀 Live Demo

🔗 [View Live Application](https://6a96d57b0a3e607ae704c27d--inventory-management-000.netlify.app/dashboard)

## ✨ Features

- 🔐 Authentication & JWT Authorization
- 👥 Role-Based Access Control (RBAC)
- 📦 Product Management — Create, Read, Update, Delete
- 📊 Inventory Management
- 👤 User Management
- 🔎 Search, Filtering & Pagination
- 📈 Dashboard Statistics & Charts
- 🔒 Protected Routes & Permission-Based Actions
- 🔔 Toast Notifications & Error Handling
- 📱 Responsive Modern UI

## ⚙️ Run Locally

```bash
git clone <your-repository-url>
cd inventory-management-client
npm install
```

Create `.env.local`:

```env
NEXT_PUBLIC_API_URL=http://localhost:3001
```

Run the application:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```
